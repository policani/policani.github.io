AI tools

AI systems I built — and open-sourced.

Subagent Operating Model

A router-first operating model for AI subagents, for Codex and Claude. One router triages each request, routes it to the fewest expert capabilities that still protect the final state, passes compact state packets, preserves ownership boundaries, and quality-gates handoffs before they become the final answer.

Open source Codex + Claude State packets
Open the model on GitHub

Portable Cross-Agent Second Brain — Personal

A solo plain-markdown second brain that gives Claude, Codex, and Cursor the same memory of how you work — two parity instruction files, no database or lock-in. The AI drafts straight into your notes (no approval queue, since you're the only user) and routes to only the note it needs, so it saves tokens. The free, frictionless edition.

Open source Claude · Codex · Cursor Saves tokens
Open repository

Portable Cross-Agent Second Brain — Team

The same second brain for shared use: a propose-then-approve gate means new material is drafted, then a human approves it before it becomes trusted team memory. Two parity files keep it working across Claude, Codex, and Cursor, and selective routing keeps the token bill down — the context economy that pays back at scale.
