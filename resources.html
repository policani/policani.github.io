Applied AI systems

AI systems I built — and open-sourced.

Subagent Operating Model

A context-safe delegation model for AI subagents, built for Codex and Claude. One router prevents agent sprawl, routes work to the fewest useful capabilities, passes compact state packets, preserves ownership boundaries, and quality-gates handoffs so supervision, trigger tuning, and least-privilege delegation stay visible.

Memventory — Personal

A private cross-tool AI memory for one person, now with a web-based Management Console: Claude, Codex, and Cursor read the same plain-markdown notes, each opening only what the task needs — and one browser page shows your whole workspace as a live map, a type breakdown, a size treemap, and a filterable table. A bundled retrieval engine answers “where is X?” before any model tokens are spent.

Job Boards Scanner

Collect and rank public employer postings so you can spend less time on stale, duplicated, closed, or low-signal roles. It filters by fit, salary, location, posting age, and source health, then exports a review list. Runs entirely in your browser.
