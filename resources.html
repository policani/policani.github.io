Career & job search

Run a sharper job search.

Job Boards Scanner

Collect and rank public employer postings so you can spend less time on stale, duplicated, closed, or low-signal roles. It filters by fit, salary, location, posting age, and source health, then exports a review list. Runs entirely in your browser.

Resume Evidence Engine

Ground every resume and cover-letter claim in real evidence, fit notes, and proof narratives, then hand off to DOCX. It doubles as an applied AI workflow-governance build — evidence-grounded generation with human review gates.

Interview Helper

Practice and interview from your own evidence, not canned answers. It turns prepared background notes into a Story Log, keeps relevant talking points handy during the conversation, and never speaks, types, or invents answers for you. Windows desktop app; bring your own OpenAI key.

AI tools

AI systems I built — and open-sourced.

Subagent Operating Model

A context-safe delegation model for AI subagents, built for Codex and Claude. One router prevents agent sprawl, routes work to the fewest useful capabilities, passes compact state packets, preserves ownership boundaries, and quality-gates handoffs so supervision, trigger tuning, and least-privilege delegation stay visible.

Open source Codex + Claude State packets
Open the model on GitHub

Portable Cross-Agent Second Brain — Personal

A private, low-friction cross-tool AI memory for one person. Claude, Codex, and Cursor read the same plain-markdown notes for preferences, decisions, workflows, and project continuity; direct ingest keeps setup light, while source and status fields preserve traceability. A standing output-discipline habit has it verify before asserting and flag uncertainty instead of guessing.

Open source Claude · Codex · Cursor Saves tokens
Open repository

Portable Cross-Agent Second Brain — Team

A team-safe portable AI memory for shared work. New material moves through a propose-then-approve gate before it becomes trusted memory, while source-grounded notes, decision history, selective routing, and stale-memory cleanup keep context useful across Claude, Codex, and Cursor. The same rigor now extends to output discipline: no placeholder or filler passed off as finished work.

Open source Approval gate Saves tokens
Open repository

AI Prose Pattern Detector

A prose-risk review tool, not an AI verdict machine. It highlights generic, over-processed, or AI-shaped patterns, warns against false certainty, and helps preserve voice across portfolio copy, professional writing, summaries, drafts, resumes, and cover letters.
