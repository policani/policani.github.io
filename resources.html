Resource list

Career, search, and writing resources.

Resume Evidence Engine

A career documentation tool that grounds resume and cover-letter drafting in actual evidence, fit notes, proof narratives, and DOCX handoff. It is also an applied AI workflow-governance build — evidence-grounded generation with human review gates and artifact lifecycle discipline, the same pattern as the AI workflow modules.

Open repository

Job Boards Scanner

A local-first job-search utility for collecting, filtering, and ranking public job postings by fit, salary, location, posting signal, and source health. It runs entirely in your browser — no account, no backend, no API key. Run it here, or download the single file for local use. Current release: v1.0.
