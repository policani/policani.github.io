Memventory · Visual Second Brain

Keep the context. Keep the boundaries.

Memventory helps people and teams carry decisions, preferences, and project context across AI tools, so they do not have to restate what matters whenever work moves to a new task or session. It preserves the local guidance that makes each piece of work distinct—without an account, database, or platform lock-in.

The visual layer

One second brain, several clear ways to explore it.

Context that respects the work

Shared memory should not make every project behave the same way.

As work spreads across projects, the rules that protect quality often stay buried with the work itself. People end up restating decisions and constraints, agents can miss local expectations, and a useful shared memory can become too generic to trust. Memventory keeps that guidance discoverable in context, so an agent can find the project-specific direction that applies before it acts.

What changes

Decisions and preferences remain available across tools, while project-level ways of working stay attached to the project. That means people spend less time restating context, with clearer handoffs and fewer avoidable context mistakes—without turning a local rule into a global one.

The views

Built to keep a growing second brain understandable.

Constellation

The signature overview — your whole vault as a living map, files clustered by folder inside rings of skills, agents, routines, and connected apps. It builds progressively on load, so you watch your own vault take shape instead of waiting on a blank screen.

Types

Every file classified by what it is — AI logic, reference, output, template, office document, media, software, or backup — with counts and total size per type. Toggle to raw file format when you need the by-extension cut. Color-coding carries across every view.

Sizes

A treemap where every file is sized by bytes and colored by role. The heavy files and folders pop immediately, so the cleanup targets choose themselves. Hover for exact size; click to inspect.

Table

A sortable, Excel-style filterable list of every file. Click a column header for sort plus a searchable checkbox filter — narrow to just AI-logic files, or just outputs, in two clicks. Select any file for a detail inspector with its role, size, sections, and references. Search, a folder tree, and per-type filters are always at hand.

How it works

Continuity without losing local control.

Memventory gives you one dependable place to keep the context that should travel between tasks—then makes it easier to see what is there, find what matters, and maintain it as work changes. Your own files stay on your machine.
