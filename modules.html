Module library

Browse by operating problem.

Intake and signal quality

Make the work visible, named, owned, and routed before it becomes false work-in-progress.

Foundation GitHub source

PPMO Formation Kit

Set up the intake lane, governance rhythm, and portfolio operating model.

Defines the operating frame the other portfolio modules can plug into.

Signal audit GitHub source

Portfolio Signal Quality Auditor

Find stale status, weak ownership, unclear readiness, and misleading portfolio signal.

Improves the quality of the inputs before scoring or executive review.

Demand triage GitHub source

Portfolio Intake Readiness Triage System

Route demand toward readiness before it drifts into unmanaged execution.

Separates ready work from ideas that still need ownership, facts, or scope.

Portfolio decisions and sequencing

Show leaders what is worth doing, what can actually be staffed, what gets delayed if they say yes, and what decision record should survive the meeting.

Priority logic GitHub source

Portfolio Prioritization Scoring Agent

Make priority tradeoffs explicit so the loudest request, pet project, or invisible override does not quietly win.

Shows why work ranks, where evidence is weak, and when capacity sequencing needs to take over.

Sequencing GitHub source

Portfolio Capacity Sequencing Planner

Sequence constrained capacity and make dependency pressure visible.

Shows what can happen now, later, or only after dependencies clear.

Decision forum GitHub source

Executive Portfolio Review Pack Builder

Turn scattered updates into a decision agenda: start, stop, sequence, fund, defer, escalate, or carry forward.

Packages executive choices, capacity pressure, sponsor asks, weak signals, and follow-up ownership.

AI workflow and artifact governance

Tame the avalanche of AI requests before pilots become commitments. This lane reviews use cases, proof burden, ownership, reliance risk, audit-ready evidence, and human approval boundaries; it does not claim model, platform, or ML ownership. For an applied example of the same pattern, see the Resume Evidence Engine.

Opportunity review GitHub source

AI Opportunity Intelligence Review System

Triage AI use-case requests by workflow value, feasibility, proof burden, duplicate overlap, ownership, and controls.

Shows which AI ideas deserve prototype, build, buy, wait, process-first, or stop routes.

Artifact control GitHub source

AI Artifact Lifecycle Governance System

Create an AI governance evidence and lifecycle registry for tools, agents, dashboards, scripts, decisions, and reliance boundaries.

Shows what exists, who owns it, who relies on it, and what evidence is needed to promote, hold, demote, or retire it.

Pattern library GitHub source

Operating Patterns

Apply generalized governance patterns and source artifacts across operating scenarios.

Provides reusable governance patterns that sit underneath several modules.

Authorization and initiation

Stop weak ideas from becoming authorized work. Challenge the investment logic first, then turn approved intent into clear scope, ownership, governance, and delivery handoff.

Investment case GitHub source

Business Case System

Challenge problem framing, options, Do Nothing, benefits, assumptions, risks, and value evidence before a sponsor decides.

Shows whether a case is ready for sponsor review, finance review, chartering, scoring, or more evidence.

Initiation GitHub source

Project Charter Initiation Agent

Translate approved intent into authorized scope, decision rights, success measures, risks, dependencies, and change control.

Frames authorization without inventing business-case logic or pretending the project is approved by the module.

Delivery readiness, controls, and outcomes

Track build and test evidence, blockers, evidence gaps, controls, signoffs, benefits, confidence, and follow-through.

Operating log GitHub source

PMO Governance Operations Log

Preserve decision memory: rationale, owners, evidence, exceptions, escalations, carry-forward items, and follow-up.

Turns operating noise into accountability between review forums.

Readiness gate GitHub source

Release Readiness UAT Governance Pack

Prove delivery and UAT readiness with evidence, signoffs, launch criteria, and blockers.

Focuses the delivery checkpoint on proof, ownership, and launch criteria.

Control exposure GitHub source

Controls Exposure Governance Toolkit

Review control exposure, exceptions, evidence gaps, risk posture, and governance cadence.

Looks at exception risk and evidence gaps after work is moving.

Benefits follow-up GitHub source

Value Realization Governance Ledger

Track value claims, realization confidence, benefits, evidence quality, and follow-through.

Closes the loop on whether approved value actually became observable.
